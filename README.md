# Shikimori Sakura

Самостоятельная тема оформления профиля для [Shikimori](https://shikimori.io): сакура, сиреневая палитра, мягкое «стекло», единый каркас для всех страниц сайта. Не зависит от сторонних пресетов.

- **Плавность.** Нет анимаций при загрузке страницы. Движение есть только в ответ на действия: наведение, фокус, нажатие. Режим «уменьшить движение» в системе соблюдается.
- **Без прыжков.** Контейнер страницы одинаковый везде. Блок оценки тайтла не меняет высоту при наведении и после выставления оценки. Фон лежит на отдельном неподвижном слое и не перерисовывается при прокрутке.
- **Без пустот.** Скрываются пустые блоки: «Не состоит ни в одном из клубов», «Нет комментариев», пустые «Действия» в турнирах и т. п.
- **Охват.** Профиль, списки аниме и манги, избранное, достижения, история, страницы тайтлов и персонажей, каталог, турниры, форум, клубы, пользователи. Вёрстка адаптирована от 320 px до Full HD.

## Подключение

Откройте **Настройки → Стиль** (`https://shikimori.io/<ник>/edit/styles`) и вставьте:

```css
@import url("https://raw.githubusercontent.com/andrey03410/shikimori-sakura/v1.2.0/dist/sakura.css");
```

Личные дополнения подключаются отдельной строкой ниже. Например, анимированные значки франшиз:

```css
@import url("https://raw.githubusercontent.com/andrey03410/shikimori-sakura/v1.2.0/dist/andrey03410.css");
```

## Как Shikimori обрабатывает стиль (важно для обновлений)

Это проверено по исходникам сайта: `app/services/styles/*`, `app/models/style.rb`.

- `@import` скачивается **сервером** Shikimori **один раз, при сохранении** настроек, и встраивается в страницу. Скачивание кэшируется на 8 часов по адресу ссылки.
  Поэтому push в репозиторий профиль сам не обновит. В ссылке всегда указана версия (`v1.2.0`). Чтобы обновить тему, поменяйте версию в ссылке и сохраните настройки.
- Репозиторий должен быть публичным: сервер скачивает файл без авторизации.
- `@import` внутри скачанного файла вырезается, поэтому тема собирается в один файл.
- Фильтр сайта вырезает слова `eval`, `cookie`, `window`, `parent`, `this`, `script`, `behavior`, `expression` и др., а также символ `<`, `&#`, комментарии и `data:`-ссылки не в base64. Из-за этого, например, `scroll-behavior` превращается в `scroll-`.
  Сборка `build.py` содержит порт этого фильтра и падает, если он изменил бы хоть один символ.
- Сайт сейчас работает на двух фронтендах с разной разметкой. На новом — профиль, списки, тайтлы, каталог. На старом — турниры, форум, клубы, персонажи. При переходе между ними страница перезагружается полностью. Тема не использует анимаций появления, поэтому перезагрузка почти незаметна.

## Разработка

```
src/          исходники темы, по разделам (собираются по порядку имён)
personal/     личные дополнения, каждый файл → dist/<имя>.css
assets/       картинки темы
dist/         собранные файлы (их и подключает Shikimori)
build.py      сборка + проверка фильтром Shikimori
tools/preview.sh  push рабочей копии в ветку preview для живой проверки
```

```bash
python3 build.py            # собрать dist/
python3 build.py --check    # проверить, что dist/ актуален (так делает CI)
```

**Живой предпросмотр без сохранения в профиль.** Запустите `tools/preview.sh`, скрипт напечатает SHA коммита. Затем в консоли браузера на shikimori.io выполните:

```js
const sha = "<SHA>";
const base = `https://raw.githubusercontent.com/andrey03410/shikimori-sakura/${sha}/dist/`;
const css = await Promise.all(["sakura.css", "andrey03410.css"].map(f => fetch(base + f).then(r => r.text())));
document.getElementById("custom_css").textContent = css.join("\n");
```

**Выпуск версии.**

1. Поднимите номер в `VERSION`.
2. Выполните `python3 build.py`, закоммитьте, затем `git tag -a vX.Y.Z -m "..."` и `git push origin HEAD vX.Y.Z` (тег должен быть аннотированным).
3. Поменяйте версию в ссылках в настройках стиля и сохраните.
